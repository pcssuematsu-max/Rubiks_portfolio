# 回しやすさ評価関数の第1回試験

## 入力と仮定

- `candidates.csv` の3×3手順8件を使用。U、H、Aの3件はユーザーがNumbers表に追加したもの。
- 各元手順を、回転・鏡映した異なる表記の手順より回しやすいと**仮定**した。個人の実測時間や主観評価は未入力。
- 変換は既存の `Rubiks_3.transform` の48種を使用。同一の手順を除外すると、7件は各47候補、Hは23候補となり、計352比較。
- コストは低いほど回しやすい。特徴量は単独回転の出現回数、または単独回転と隣接2回転の出現回数。

## 最適化

各元手順を M、変換後を V、特徴量を x として、

`C(M) = w · x(M)`

`C(M) + 0.1 <= C(V) + ξ_(M,V)`、`ξ_(M,V) >= 0`、`w >= 0`、`Σw = 1`

を課した。目的関数は各元手順について平均したスラックの合計。L2補正項は使用していない。元手順ごとに平均することで、対称性によって候補数が少ないHも、他の元手順と同じ重みで扱った。

## 結果

「勝ち」は、元手順のコストが変換後より厳密に低い比較の数。`0.1` のマージン達成数も示す。

| 特徴量 | 全8件で学習した勝ち数 | 全8件で学習したマージン達成数 | 1件ずつ除外した勝ち数 | 1件ずつ除外したマージン達成数 |
| --- | ---: | ---: | ---: | ---: |
| 単独回転 | 349/352 | 346/352 | 332/352 | 300/352 |
| 単独回転＋隣接2回転 | 352/352 | 336/352 | 322/352 | 254/352 |

除外試験の勝ち数を手順別に見ると次の通り。

| 元手順 | 単独回転 | 単独回転＋隣接2回転 |
| --- | ---: | ---: |
| T | 47/47 | 47/47 |
| Jb | 47/47 | 47/47 |
| Y | 47/47 | 46/47 |
| Sune | 39/47 | 42/47 |
| Anti-Sune | 47/47 | 47/47 |
| U | 46/47 | 46/47 |
| H | 23/23 | 23/23 |
| A | 36/47 | 24/47 |

単独回転モデルには27特徴、隣接2回転を加えると459特徴ある。後者は入力例への当てはまりが高いが、除外試験では特にAの順位を崩した。この候補数では2回転係数の推定に十分な根拠がない可能性が高い。

最大の単独回転コストは `B`、`B'`、`D`、`D'` に付いた。これは「元手順が使わない面の手を含む変換」を見分ける効果が強い。人間の指使いを表していると解釈するには早い。また、L2補正なしの係数は一般に一意ではないため、各係数の細かな値より比較成績を重視する。

## 次に検討すること

1. 各元手順が本当に回しやすいか、初期グリップとともに評価する。似た変換も同等に回しやすい場合は、その比較を除外する。
2. 48変換のうち、上下を入れ替えて明らかに不利になる比較を減らし、左右反転や上面を保つ回転など、より近い候補に絞って再試験する。
3. 2回転特徴を使うなら、頻出する組だけに絞り、手順単位の除外試験で改善するか確認する。

手数が異なる手順同士の総実行時間は、この同手数の対称変換比較だけからは決められない。

## 第2回試験: L2補正

比較条件と `w >= 0`、`Σw = 1` は同じまま、目的関数を「平均スラック + λ/2 × Σw²」に変更した。λを0.01、0.1、1.0で試した。下表は1手順ずつ除外した結果であり、勝ち数とマージン達成数はいずれも352比較中の数。平均スラックは8件を等重みで平均した値。

| 特徴量 | λ | 勝ち数 | マージン達成数 | 平均スラック |
| --- | ---: | ---: | ---: | ---: |
| 単独回転 | 0 | 332 | 300 | 0.014290 |
| 単独回転 | 0.01 | 335 | 302 | 0.010581 |
| 単独回転 | 0.1 | 338 | 309 | **0.008490** |
| 単独回転 | 1.0 | 342 | 269 | 0.010489 |
| 単独回転＋隣接2回転 | 0 | 322 | 254 | 0.021277 |
| 単独回転＋隣接2回転 | 0.01 | 343 | 262 | 0.013132 |
| 単独回転＋隣接2回転 | 0.1 | 343 | 260 | **0.010813** |
| 単独回転＋隣接2回転 | 1.0 | 346 | 208 | 0.016025 |

λ=0.1が両モデルで平均スラックを最小にした。λ=1.0は厳密な勝ち数を増やす一方、差が縮むためマージン達成数を減らした。特徴数が27と459で異なるので、同じλは係数への実効的な影響も同じとは限らない。

係数上位5個の合計は、単独回転モデルではλ=0の約0.551からλ=0.1の約0.412に、隣接2回転モデルでは約0.307から約0.249に下がった。L2によって重みの集中が弱まった。ただし、これは係数の数値的安定性の話であり、回しやすさの実測による検証ではない。

### λ=0.1で元手順より低コストになった変換

全8件で学習した単独回転モデルでは、Sune `R U R' U R U2 R'` のFB鏡映 `R' U' R U' R' U2 R` が低コストだった（元手順0.104200、鏡映0.004201）。Uの `M2 U' M' U2 M U' M2` とAの `R' U R' D2 R U' R' D2 R2` は、それぞれの元手順と同点だった。隣接2回転も使うモデルでは、元手順より低コストまたは同点の変換はなかった。ここでの「低コスト」はモデル内の判定であり、実際の指使いによる優劣ではない。
