# margin と L2 を外した試験

前回と同じ全22手順を7x7として扱い、重複除去後の2,018比較を使用した。非負係数の和1、各元手順を等重みにした平均ヒンジ損失は維持した。係数の値や「勝ち数」は全件で学習した結果であり、除外評価がある条件は別記する。

| 特徴量 | margin | L2係数 | 全件学習の勝ち / 同点 / 負け | margin達成 | 平均ヒンジ損失 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 単独回転 | 0.1 | 0.1 | 1,949 / 39 / 30 | 1,588 | 0.008924 |
| 単独回転 | 0.1 | 0 | 1,958 / 30 / 30 | 1,638 | 0.008878 |
| 単独回転 | 0 | 0.1 | 0 / 2,018 / 0 | 2,018* | 0 |
| 単独回転＋隣接2回転 | 0.1 | 0.1 | 1,961 / 30 / 27 | 1,623 | 0.008024 |
| 単独回転＋隣接2回転 | 0.1 | 0 | 1,895 / 95 / 28 | 1,772 | 0.007869 |
| 単独回転＋隣接2回転 | 0 | 0.1 | 0 / 2,018 / 0 | 2,018* | 0 |

*marginが0なら同点も「margin達成」なので、この列は比較に使えない。L2なしの2回転モデルは平均ヒンジ損失とmargin達成数は改善したが、厳密な勝ち数は減った。厳密な勝ち数は最適化目標ではない。

## `2B`と`S`を含む候補

前回の逆転は、L2を外しても残った。差は「変換後 − 元手順」で、負なら変換後を低コストと判定する。

| 特徴量 | L2係数 | ID 12：`2B`候補との差 | ID 21：`S`候補との差 |
| --- | ---: | ---: | ---: |
| 単独回転 | 0.1 | −0.041676 | −0.022223 |
| 単独回転 | 0 | −0.047878 | −0.029899 |
| 単独回転＋隣接2回転 | 0.1 | −0.039278 | −0.039283 |
| 単独回転＋隣接2回転 | 0 | −0.045023 | −0.045023 |

単独回転モデルでL2を外すと、`F`・`F'`の係数は各約0.03055、`2B`・`2B'`は各約0.02606、`S`・`S'`は各約0.03505になった。元手順にある4回の`F`系を、変換後の2回の`2B`系または`S`系などで置き換えると、依然として変換後の合計コストが小さい。したがって、逆転の主因をL2だけには帰せない。

## marginを0にすると何が起こるか

全候補は元手順と同じ手数で、隣接2回転の数も同じ。すべての単独回転係数を同じ値にすれば、どの変換も元手順と同点になる。2回転込みでも、すべての特徴量係数を同じ値にすれば同じことが起こる。このときヒンジ損失は0で、係数の和1という条件のもとでは一様係数がL2も最小にする。実際の解は単独回転63係数がすべて `1/63`、2回転込み1,179係数がすべて `1/1179` となり、除外評価でも2,018比較すべて同点だった。

marginとL2を両方0にすると、損失0の解が多数ある。例えば、元手順に出ない`2B`だけに重み1を置く解は160勝・1,858同点、`S`だけに重み1を置く解は128勝・1,890同点で、どちらも損失0の最適解である。最適化だけでは順位を選べない。

前回条件（margin 0.1、L2 0.1）の1手順除外評価は単独回転で1,881/2,018勝、2回転込みで1,892/2,018勝。margin 0、L2 0.1の除外評価は両モデルとも0勝・2,018同点。L2だけを外した条件は全件学習での比較であり、除外評価は未実施。今回の全件学習での小さな損失改善は、未知の手順への改善を示さない。
