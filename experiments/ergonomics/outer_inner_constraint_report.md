# 外層より内層を高コストにする制約の試験

前回と同じ全22手順・2,018比較、margin 0.1、L2係数0.1、係数非負・和1を維持した。単独回転モデルについて、外層18種類（U/D/F/B/L/Rと回転量・向き）すべての係数が、内層45種類（2層・3層とM/S/E）すべての係数より少なくとも0.001低いという制約を加えた。厳密な不等号を数値最適化に使うため、0.001の差で近似した。

| 指標 | 制約なし | 外層＜内層 |
| --- | ---: | ---: |
| 全件学習の勝ち数 | 1,949/2,018 | 1,878/2,018 |
| 1手順除外の勝ち数 | 1,881/2,018 | 1,822/2,018 |
| 全件学習のmargin達成数 | 1,588/2,018 | 356/2,018 |
| 全件学習の平均ヒンジ損失 | 0.008924 | 0.035440 |
| 手順12の最低候補との差（変換後−元） | −0.041676 | −0.033278 |
| 手順21の最低候補との差 | −0.022223 | 0 |

制約を加えた解では外層係数の最大値が約0.012499、内層係数の最小値が約0.013499となり、条件を満たした。手順21の`S`を使う逆転は消えたが、手順12の`2B`を使う逆転は残った。新たに手順13にも約−0.008306の逆転が出た。

0.001という差への依存を確認すると、差を0、0.001、0.005と変えても、手順12にはそれぞれ16件の元手順より低い変換が残った。全件学習の勝ち数は順に1,848、1,878、1,842であり、0.001を選ぶだけで結論が生まれたわけではない。

## なぜ手順12の逆転が残るか

元手順には`2U`系が2回、変換後には`2B`系が2回ある。どちらも内層回転なので、「内層全体を外層より高くする」共通の上乗せは比較で相殺される。差を作るのは、`2B`と`2U`の**内層同士**の係数差、および外層の`F`系と`U`系の係数差である。

実際、現在の回転・鏡映・2–3層交換・`flip_inside`は外層の手を内層へ変えず、内層の手を外層へも変えない。各元手順と変換後で外層の手数・内層の手数がそれぞれ等しい。したがって、この比較データからは「外層全体と内層全体の基本コスト差」を学習・検証できない。この制約は外部から与える仮定である。

隣接2回転モデルは単独回転の係数だけを順序付けても、隣接ペアの係数が文脈内の総コストを覆しうるため、今回の制約の意味が不明確になる。まず単独回転モデルだけを試した。

この試験では全外層を全内層より安くする条件は順位の再現性を下げた。より直接的な次のデータは、同じ持ち方で`2U`と`2B`、`E`と`S`を含む手順を実際に比較した評価である。同じ目的を達成し、外層と内層の使用回数が異なる手順同士の比較も、層ごとの基本コストを推定する手掛かりになる。
